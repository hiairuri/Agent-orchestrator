## 1. ID 与分层规则

- ID 体系：`A-v<版本三位>-<组><两位序号>`；v0.5 CR-V 子断言带组名前缀（`A-v050-CRV1-01`…`CRV4-05`），机制断言 `A-v050-M01`…`M10`（D3 §9.3 行文短写 M-01…M-07，DA4 补 M-08…M-10）。
- 替代关系规则：被替代条目不删除，加"已被 A-vxxx-xx 替代——仅考古勿复跑"（现例 A-v031-S01/S05→A-v041-V01/V02）；措辞随实现修订的以注记录差异、主句保历史原文。
- 回归分层（CR-15，对接 run-all.mjs `--layer`）：**L0 骨架**（node --check / tools/list / BOARD_VERSION / hooks.json 字节 / SB09 静态红线）/ **L1 直接**（SB/D 组、CR-V 全部、M 组、bg-gate B/S09 组——机制行为断言，全跑）/ **L2 邻接**（哨兵 live V 组、lessons/journal/stop-check 等——抽样）/ **L3 远端**（手工观察、文档审查类——免跑日常，发版前人工清单）。条级标注可覆盖组级默认。
- 分层执行载体：L0=`tests/suites/l0-skeleton.mjs`；L1=`tests/suites/{sb-normalize,crv1-scope,crv2-pack,crv4-audit,crv3-present,condense,bggate}.mjs`；L2/L3 现为手工/独立脚本项（映射表 §3 给出执行方式），入口 `node tests/run-all.mjs [--layer L0|L1|all] [--ids <suite名,…>]`；日常冒烟 `node tests/run-smoke.mjs`（≤60s，=L0+板面回环）。
